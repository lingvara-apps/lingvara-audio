## Lenguaje de desarrollo de software
codebase | base de código | La base de código es tan antigua que nadie se atreve a tocar el módulo de pagos.
refactor | refactorizar, reorganizar el código | Antes de añadir nuevas funciones, deberíamos refactorizar esta función desordenada.
legacy code | código heredado, código antiguo | María pasó todo el ciclo depurando código heredado escrito hace quince años.
technical debt | deuda técnica | Cada atajo que tomamos ahora aumenta nuestra deuda técnica más adelante.
hotfix | parche urgente, corrección rápida | Lanzamos un parche urgente a medianoche después de que la página de inicio de sesión dejara de funcionar.
roll back | revertir, volver a la versión anterior | La actualización hizo colgar la aplicación, así que tuvimos que revertirla a la versión anterior.
deploy | desplegar, poner en producción | Nunca desplegamos los viernes, porque nadie quiere arreglar errores en fin de semana.
pull request | solicitud de extracción, petición de integración | Por favor, abre una solicitud de extracción para que el resto del equipo pueda revisar tus cambios.
backlog | cartera de tareas pendientes, lista de pendientes | La cartera de tareas tiene ahora más de trescientos tickets que nadie ha mirado.
scope creep | ampliación descontrolada del alcance | Gracias a la ampliación descontrolada del alcance, un proyecto de dos semanas ha tardado cuatro meses.
## Errores y depuración
edge case | caso límite, situación extrema | La aplicación funciona bien hasta que alguien introduce un nombre con apóstrofo, un caso límite clásico.
workaround | solución temporal, rodeo | Aún no hay solución oficial, pero existe un rodeo: exporta el archivo como texto primero.
kludge | chapuza informática, solución improvisada | Todo el sistema se sostiene gracias a una chapuza que solo Camille entiende.
spaghetti code | código espagueti, código enrevesado | Nadie quiere mantener ese código espagueti, así que lleva años sin actualizarse.
regression | regresión, fallo reaparecido | La nueva actualización introdujo una regresión: el botón de exportar ya no funciona.
race condition | condición de carrera | Resultó que los cuelgues aleatorios se debían a una condición de carrera entre dos hilos.
memory leak | fuga de memoria | Al cabo de unas horas el servidor se ralentiza, lo que sugiere una fuga de memoria.
stack trace | registro de la pila de llamadas, traza de error | Por favor, pega la traza de error completa en el ticket para que podamos ver dónde falló.
rubber duck debugging | depuración por el método del patito de goma | La depuración por el patito de goma funciona: explicar el código en voz alta suele revelar el error.
dogfooding | comerse la propia comida, usar el propio producto | Usar nuestro propio producto nos ayudó a encontrar docenas de molestos errores antes que los clientes.

helpdesk | mesa de ayuda, servicio técnico | He abierto una incidencia en la mesa de ayuda, pero aún no han respondido.
