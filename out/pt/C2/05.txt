## Linguagem de desenvolvimento de software

legacy code | código legado | Maria passou o sprint inteiro desatando o nó de um código legado escrito quinze anos atrás.

hotfix | correção rápida, hotfix | Lançamos um hotfix à meia-noite depois que a página de login parou de funcionar.
roll back | reverter para uma versão anterior | A atualização travou o aplicativo, então tivemos que reverter para a versão anterior.
deploy | colocar em produção, implantar | Nunca fazemos deploy às sextas-feiras, porque ninguém quer consertar bugs no fim de semana.
pull request | solicitação de pull, pull request | Por favor, abra um pull request para que o resto da equipe possa revisar suas alterações.
backlog | fila de tarefas, backlog | O backlog agora tem mais de trezentos chamados que ninguém olhou.
scope creep | aumento descontrolado do escopo | Graças ao aumento descontrolado do escopo, um projeto de duas semanas já levou quatro meses.
## Erros e depuração
edge case | caso limite, situação atípica | O app funciona bem até alguém digitar um nome com apóstrofe, um clássico caso limite.
workaround | contorno, solução alternativa | Ainda não há correção, mas há um contorno: exporte o arquivo como texto primeiro.
kludge | solução remendada, gambiarra | O sistema inteiro se segura por uma gambiarra que só a Camille entende.
spaghetti code | código macarrônico, código confuso | Ninguém quer dar manutenção naquele código macarrônico, então ele não é atualizado há anos.
regression | regressão (erro que reaparece) | A nova atualização introduziu uma regressão: o botão de exportar não funciona mais.
race condition | condição de corrida | Descobriu-se que as travas aleatórias eram causadas por uma condição de corrida entre duas threads.
memory leak | vazamento de memória | Depois de algumas horas o servidor fica lento, o que sugere um vazamento de memória.
stack trace | rastro da pilha, stack trace | Cole o rastro da pilha completo no chamado para podermos ver onde falhou.
rubber duck debugging | depuração com patinho de borracha | A depuração com patinho de borracha funciona: explicar o código em voz alta geralmente revela o erro.
dogfooding | uso interno do próprio produto | O uso interno do produto nos ajudou a achar dezenas de bugs irritantes antes dos clientes.
