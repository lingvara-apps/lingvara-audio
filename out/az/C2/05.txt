## Proqram təminatı dili

refactor | kodu yenidən qurmaq | Before adding new features, we should refactor this messy function.
legacy code | köhnə miras kod | Maria spent the whole sprint untangling legacy code written fifteen years ago.
technical debt | texniki borc | Every shortcut we take now adds to our technical debt later.
hotfix | operativ düzəliş | We pushed a hotfix at midnight after the login page stopped working.
roll back | əvvəlki versiyaya qayıtmaq | The update crashed the app, so we had to roll back to the previous version.
deploy | proqramı serverə quraşdırmaq | We never deploy on Fridays, because nobody wants to fix bugs at the weekend.
pull request | kod birləşdirmə sorğusu | Please open a pull request so the rest of the team can review your changes.
backlog | gözləmədə olan tapşırıqlar siyahısı | The backlog now has over three hundred tickets that nobody has looked at.
scope creep | layihə həcminin nəzarətsiz şəkildə böyüməsi | Thanks to scope creep, a two-week project has now taken four months.
## Xətalar və səhvlərin aradan qaldırılması

workaround | müvəqqəti çıxış yolu | There's no fix yet, but there is a workaround: export the file as text first.
kludge | quraşdırma (müvəqqəti və səliqəsiz həll) | The whole system is held together by a kludge that only Camille understands.

regression | funksiyanın sıradan çıxması xətası | The new update introduced a regression: the export button no longer works.
race condition | resurs uğrunda yarış xətası | The random crashes turned out to be caused by a race condition between two threads.
memory leak | yaddaş sızması | After a few hours the server slows down, which suggests a memory leak.
stack trace | xəta yığını hesabatı | Please paste the full stack trace into the ticket so we can see where it failed.
rubber duck debugging | səslə düşünərək səhvi tapma üsulu | Rubber duck debugging works: explaining the code aloud often reveals the mistake.
dogfooding | öz məhsulundan şəxsən istifadə etmə | Dogfooding helped us find dozens of annoying bugs before customers did.
